# HomeJira — Manual UI Test Plan

Test against **production**: https://homejira.app
Run top to bottom. Each section depends on the previous.
Use two different browsers or private windows to simulate multiple users.

---

## Setup

You need two test accounts. Use usernames you control, or use these reserved test usernames:
- **User A (Admin):** username `testuser_a` / mPIN `1234`
- **User B (Member):** username `testuser_b` / mPIN `1234`

If these already exist, skip registration and go straight to Login.

---

## 1. Auth — Registration

**Browser 1 → User A**

1. Go to https://homejira.app
2. Verify onboarding page loads with "Create account" and "Sign in" buttons
3. Tap **Create account**
4. Enter username `testuser_a` → tap Next
5. Enter name e.g. "Alice"
6. Set mPIN `1234` → confirm `1234`
7. Verify you land on the Tasks page (`/`) with bottom nav visible

**Browser 2 → User B**

8. Repeat steps 1–7 with username `testuser_b`, name "Bob"

## 2. Auth — Login

1. In Browser 1, open Account menu (top-right avatar) → tap **Sign out**

## 23. Auth Edge Cases

| Scenario | Expected |
|----------|----------|
| Wrong mPIN at login | Error message, no redirect |
| Duplicate username registration | Error: username already registered |
| Expired/invalid invite link | "This invite link is invalid or has expired." |
| Invalid join code | "Invalid code. Please try again." |
| Joining household you're already in via invite link | 422 error shown |
| Accessing `/` while logged out | Redirect to `/auth` |
| Accessing `/auth` while logged in | Redirect to `/` |

## 24. Health Check

Run after every deployment:

```bash
curl -s https://homejira.up.railway.app/health
# Expected: {"status":"ok","db":"ok","env":"production",...}

curl -s -o /dev/null -w "%{http_code}" https://homejira.up.railway.app/api/v1/tasks
# Expected: 401

curl -s -o /dev/null -w "%{http_code}" -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser"}' \
  https://homejira.up.railway.app/api/v1/auth/check-username
# Expected: 200
```

Any `5xx` response = release blocker. Roll back immediately.
